# 电商图片提取下载插件

一个 Chrome 浏览器扩展，一键提取电商详情页所有商品图片，支持淘宝、京东、拼多多，批量下载为 PNG 格式。

## 功能特性

- 📦 支持淘宝、天猫、京东、拼多多等主流电商平台
- 🖼️ 自动提取页面所有商品图片
- ✅ 支持全选/反选，按需下载
- ⬇️ 批量下载，自动命名
- 🎨 简洁美观的界面

## 安装方法

1. 打开 Chrome 浏览器，地址栏输入 `chrome://extensions/` 回车
2. 打开右上角的「开发者模式」开关
3. 点击左上角「加载已解压的扩展程序」
4. 选择本项目文件夹（`电商图片下载插件`）
5. 安装完成，插件会出现在扩展列表中

## 使用方法

1. 打开任意电商商品详情页（淘宝、京东、拼多多等）
2. 页面右下角会出现「获取图片」按钮
3. 点击按钮，插件会自动提取页面所有图片
4. 提取完成后会自动打开图片画廊页面
5. 勾选要下载的图片，点击「下载选中」即可批量下载

## 文件结构

```
电商图片下载插件/
├── manifest.json      # 插件配置文件
├── content.js         # 内容脚本（注入按钮 + 提取图片）
├── content.css        # 按钮样式
├── background.js      # Service Worker（处理下载与消息转发）
├── gallery.html      # 图片画廊页面
├── gallery.js         # 画廊页面交互逻辑
├── gallery.css        # 画廊页面样式
├── icons/            # 插件图标
└── README.md          # 安装说明
```

## 技术说明

- 使用 Manifest V3 规范
- 纯原生 JavaScript，无任何依赖
- 支持跨平台域名匹配
